# Physics Simulation

Project for IB Comp Sci IA 2026:
Simulating ridgid body physics. This project will be a interactable physics simulation that accuratly simulates interactions between ridgid bodies.
<br /> 
For the physics calculations the BRidgid library is used.

The program allows the user to modify the physics simulation by adding and modifying objects. The user is also able to pause and unpause the simulation. The physics calculations will be handled by the library and then the graphics will be updated accordingly, along with the values of each of the objects in the simulation.

This will be coded using Processing, which will also handle graphics.
